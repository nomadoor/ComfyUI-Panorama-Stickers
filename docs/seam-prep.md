# Panorama Seam Prep

`PanoramaSeamPrep` ノードの規則を定める。パノラマ（ERP）の左右のつなぎ目を画像の中へ動かし、つなぎ目を直す
（inpainting する）ためのマスクを作る。

## この文書が owner である規則

| 規則 | Python | JS | test |
|---|---|---|---|
| つなぎ目を動かす量と、マスクの帯の位置 | `comfyui_pano_suite/seam_prep.py` `PanoramaSeamPrepNode` | — | `tests/test_seam_prep.py` |

## つなぎ目とマスク

- 入力の画像を横に回し（左右をつないだ 360° の画像として、はみ出した分を反対の端へ回す）、元の左右の端（つなぎ目）を
  画像の真ん中から `seam_center_offset_px` だけ右へ置く（負なら左）。
- `mask` は、つなぎ目を真ん中にした幅 `seam_width_px` の縦の帯を 1、ほかを 0 にする。`mask_blurred` は `mask` を
  `mask_blur_px` でぼかしたもの。帯の真ん中は、出力の画像の上のつなぎ目と同じ位置にする。
- 帯はいつも画像の中に丸ごと収める。つなぎ目の両側が一枚の画像に並んで見えるようにするため（帯が左右の端で二つに
  分かれると、直すときにつなぎ目の両側を一度に見られない）。そのため、`seam_center_offset_px` は、帯が画像の中に
  丸ごと収まる範囲で止める。止めたことは知らせない。`seam_width_px` が画像の幅以上のときは、動かす量は 0 にする
  （帯が画像の全体になる）。
- `seam_width_px` が奇数のとき、余る 1 画素はつなぎ目の右に置く（幅が偶数の画像での今までの置き方。幅が偶数の画像では、
  範囲の中の値の出力は今までと画素まで同じ。幅が奇数の画像で `seam_width_px` も奇数のときは、帯が今までより 1 画素右になる）。幅が奇数の画像では、動かす前のつなぎ目は真ん中より右の画素の境目にある。
  この二つのため、右へ動かせる量は左へ動かせる量より、画像の幅と `seam_width_px` のうち奇数のものの数だけ（0〜2 画素）少ない。
- 画像と `mask` と `mask_blurred` は、いつも同じ（止めた後の）動かす量から作る。
