# ADR 0052: ノード上の表示はエディタで見える物をすべて描き、再生できる

## Status

Proposed（2026-10-31）

## Date

2026-10-31

---

## 背景

ADR 0049 は、Panorama Studio のノード上の表示を撮る Camera の出力をその場で描く絵にしたが、上流の Scene の層と深度の格子の 3D は
「まだ描かない（描くまでは実行の結果と違う）」とした。ADR 0029 はノード上の再生ボタンをやめた。

持ち主（デザイナー）が `world` に MoGe の動画（深度の格子の列）をつないで試し、「ノード上のプレビューが 1 フレーム目の描画にもなっていない。
動画として再生もできない」と報告した（2026-10-31）。調べると、ノード上は深度の格子を描かない spec のとおりで、エディタ（2026-10-31 から
深度の格子を描く）と見える物が違っていた。

持ち主の決定：「上流云々ではなく、モーダルの UI で見れるものはそのまま見れないといけない」。再生はできるようにし、簡単にする。

## 決定

- ノード上の表示は、エディタの Output の小窓と同じ物を描く。エディタで見える物はノード上でもそのまま見える。上流の Scene の層と
  深度の格子（色のプロキシの動画を表示フレームに合わせる）も描く。エディタで新しく描く物を足すときは、同じ変更でノード上にも足す。
- ノード上に再生のボタンを置く：再生できるときだけ、`Open Studio` の左に 30px の丸いボタン（持ち主が三案から選んだ A）。
  押すと再生と一時停止。再生位置の線、時刻、頭出し、キーは持たない。収まらない細いノードでは `Open Studio` をアイコンだけにする。
  同時に再生できるのは一つのノードだけ（ほかは一時停止する）。
- 再生できるかは、エディタと同じく Timeline の長さが 1 フレームより長いときとし、ノード上の別の条件（`isTimed` と入力の列挙）をやめる
  （深度の格子の列だけのノードが、ノード上では再生できないと判定されていた）。
- 規則は `docs/studio-node-surface.md`（「表示の構成」「撮る Camera の出力をその場で描く」「表示フレームと VIDEO」「再生のボタン」）、
  `docs/studio-ui.md`（「ノードの入力から来た物」）、`docs/design.md`（「Panorama Studio のノード上の表示」）が持つ。

## 試して捨てた案

- 再生のボタンを絵の左下の角に置く（B）、絵の下の一行に小さなボタンと時刻を置く（C）：持ち主が A を選んだ。
- 再生位置の線と頭出し：簡単にするため置かない（頭出しはエディタで）。
- 上流の層だけ・深度の格子だけを個別に足す：個別に足すと、また「エディタでは見えるのにノードでは見えない」物が出る。原則で決める。

## Consequences

- ノード上の絵とエディタの Output の小窓が同じ物を示し、実行前に出力を確かめられる。
- 深度の格子と上流の層の分、ノード上の描画と素材（色のプロキシの動画）の読み込みが増える。見えないときとエディタを開いている間に放す
  規則（`docs/studio-node-surface.md` の「見えないときとエディタを開いている間」）はそのまま当てる。
