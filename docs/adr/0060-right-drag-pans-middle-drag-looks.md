# ADR 0060: 右ドラッグはパン、中ボタンのドラッグは見回しにする

## Status

Proposed（2026-11-03）

ADR 0047 の割り当てのうち、「右ドラッグ（どこでも）は、その場の見回し」と「中ボタンのドラッグはパン」を入れ替える。
Alt との組み合わせ（Alt + 左・右ドラッグのオービット、Alt + 中ボタンの前後のジョイスティック）、何もないところの左ドラッグの見回し、
ホイール、WASD / QE は変えない。

## Context

ADR 0047 では、右ドラッグは何もないところの左ドラッグと同じ見回しで、違いは物の上でも物に触らないことだけだった。パンは押しにくい
中ボタンにしかなかった。ComfyUI のコアの Load3D（OrbitControls）は右ドラッグが移動（パン）で、ComfyUI の利用者の手はそちらに慣れている。
持ち主が「右クリックと中クリックは逆のほうがいいのか」と挙げ、入れ替えると決めた（2026-11-03）。

## Decision

- 右ドラッグ（どこでも、物の上でも物に触らない）はパン。中ボタンのドラッグ（どこでも、物に触らない）は見回し。
- Panorama 表示、Camera タブの Frame 表示、Preview のウィンドウで同じ。

## Consequences

- パンが右ボタンでできる。物が画面いっぱいにあって左ドラッグが物に取られるときの見回しは、中ボタンでできる。
- Unity や Unreal の「右ドラッグで見回しながら WASD で飛ぶ」は使えない。左ドラッグ・中ボタンの見回しの間も WASD は効く。
- 視点の操作の部品の手の tooltip を「right-drag in the view」に、ショートカットの一覧を直す。
