# ADR 0060: 右ドラッグはパン、中ボタンのドラッグは見回しにする

## Status

Proposed（2026-11-03）

ADR 0047 の割り当てのうち、右ボタンと中ボタンの役割を Alt との組み合わせごと入れ替える：「右ドラッグ（どこでも）は、その場の見回し」と
「中ボタンのドラッグはパン」、「Alt + 右ドラッグはオービット」と「Alt + 中ボタンは前後のジョイスティック」。何もないところの左ドラッグの
見回し、Alt + 左ドラッグのオービット、ホイール、WASD / QE は変えない。

## Context

ADR 0047 では、右ドラッグは何もないところの左ドラッグと同じ見回しで、違いは物の上でも物に触らないことだけだった。パンは押しにくい
中ボタンにしかなかった。ComfyUI のコアの Load3D（OrbitControls）は右ドラッグが移動（パン）で、ComfyUI の利用者の手はそちらに慣れている。
持ち主が「右クリックと中クリックは逆のほうがいいのか」と挙げ、入れ替えると決めた（2026-11-03）。最初の案は Alt との組み合わせを
変えずに残し、右ボタンだけが「Alt なしはパン、Alt ありはオービット」と組の違う二つを持った。持ち主が「Alt の挙動も合わせろ」と挙げ、
Alt との組み合わせごと入れ替えた（同日）。

## Decision

- 右ドラッグ（どこでも、物の上でも物に触らない）はパン、Alt + 右ドラッグは前後のジョイスティック。中ボタンのドラッグ（どこでも、物に
  触らない）は見回し、Alt + 中ボタンのドラッグはオービット。回す操作（見回し・オービット）は左と中ボタン、動かす操作（パン・前後）は
  右ボタンにまとまる。Alt は、どのボタンでも同じ組の中のもう一つに替える。
- Panorama 表示、Camera タブの Frame 表示、Preview のウィンドウで同じ。

## Consequences

- パンが右ボタンでできる。物が画面いっぱいにあって左ドラッグが物に取られるときの見回しは、中ボタンでできる。
- Unity や Unreal の「右ドラッグで見回しながら WASD で飛ぶ」は使えない。左ドラッグ・中ボタンの見回しの間も WASD は効く。
- 視点の操作の部品の tooltip（球「Alt+left-drag」、手「right-drag」、矢印「Alt+right-drag」）と、ショートカットの一覧を直す。
