# ADR 0065: Camera は Look at で相手を向き続けられる

## Status

Proposed（2026-11-17）

ADR 0038 の「撮りにくい動きが出たら、Keyframe の側に足す」の、向きについての形を定める。

## Date

2026-11-17

---

## 背景

被写体を見たまま回り込む Camera の動きは、持ち主が「非常に重要」とした動きである。位置の Keyframe と向きの Keyframe だけで作ると、Keyframe ごとに向きを合わせる必要があり、Keyframe の間で向きが被写体からずれる。Orbit のような命令は、「どの距離で、いつ始めて」が決めにくい（持ち主）。ほかの道具（Blender の Track To、Unreal Engine の Look at Tracking、Google Earth Studio の Camera Target）は、向きを「相手との関係」として持つ。

## 決定

- Camera に、向く相手を持つ Lane（`look_at`）を足す。相手は、World の物とその上の一点、World の一点、相手なしのどれか。相手があるとき、Camera の向きは相手から決まる。
- **状態は大きい形で持ち、画面は小さく始める**（ADR 0064 の土台の 2）。Lane は Keyframe を持てて、途中から向く・相手を変える・途中でやめる、を表せる。画面が今出すのは、相手一つが Timeline の全体に効く形だけである。
- 相手は、スポイトのように拾う。Pick を押してから、物の上の見たい所を押す。押した点を、物の中身の箱に対する割合のずれとして持つので、人の画像の顔を見続ける、ができる。割合なので、中身を入れ替えても（Replace は同じ物のまま中身だけを替える）、切り抜きや縦横比が変わっても、同じ所を指す。
- **Look at が決めるのは向きだけで、軌道の形は変えない。** 回り込みの弧は、軌道の点を Bezier にしてハンドルで作るか、Keyframe を足す。相手があるときだけ軌道を弧にする決まりは、Auto の点にしか効かず、ハンドルを触ったことがあるかで結果が変わる見えない決まりになるので、作らない（持ち主）。
- 向いている間の上は、いつも World の上。傾きは Roll の値をそのまま使う。特別に扱うのは、相手のちょうど真上・真下だけである。そこでは左右の向きを、すぐ前のフレームの向き、無ければすぐ後、どちらも無ければ `rotation` の Lane から取る。真上をまたぐと絵が半回転することは受け入れる。
- 向いている間、Camera タブのドラッグは相手の周りを回り、ホイールは相手との距離を変える。相手を切り替えている途中の区間では、Camera タブのドラッグとホイールを止めて理由を知らせる。
- 向いていることは、インスペクタで見せる。Camera のカードの見出しに「Look at」の印を出し、Look at の行を点ける。タイムラインには印を足さない。ステージの見ている点の印と点線は、Camera と同じ黄色で描く（数字は `docs/design.md`）。
- 下流へ渡す `sticker_state` には、Look at を関係のまま渡す（相手の Lane と、相手の動き。ADR 0067）。向いた結果をフレームごとに焼くことはしない。

## 境界をまたぐ設計（AGENTS.md の原則 4）

### 作らないもの

- 相手を画面の真ん中から外した構図、追いかけの遅れ、置いた物が何かを向く設定、上流の物を相手にすること。
- 相手を途中で変える・途中だけ効かせる画面（状態と評価は受け付ける）。
- 相手に合わせて軌道の形を変えること。

### どの規則をどこが持つか

| 規則 | 持つ文書 |
|---|---|
| `look_at` の Lane の形と正規化、相手から向きを求める規則、決まらない方向の扱い、Keyframe の間の混ぜ方 | `docs/scene-state-v2.md` の「向く相手の値」と「Look at」 |
| 方向から向きへの変換（World の glTF 座標と、パノラマの角度の規約をつなぐ） | `docs/scene-state-v2.md` の「座標と角度」。コードは `core/world.py` と `web_src/pano_world.js` の一か所ずつ |
| Camera のカードの行、Pick、見ている点の印、向いている間に無効にする部品、Camera タブのドラッグ | `docs/studio-ui.md` の「Look at」 |
| 中身の箱を評価関数に渡すこと（Python はノードが読んだ素材から、JS はエディタが読み込んだ中身から） | `docs/studio-node.md`、`docs/studio-ui.md` の「Look at」 |
| `sticker_state` で Look at を関係のまま渡すこと | `docs/scene-state-v2.md` の「`sticker_state`」（ADR 0067） |

### data の流れ

- エディタは `camera.look_at` に相手を書く。評価関数（Python と JS）は、同じ時刻の相手の位置を求め、Camera の位置からの方向を向きに直す。
- 評価の戻り値の Camera の向き（`yaw_deg`・`pitch_deg`・`roll_deg`）が、相手を向いた向きになる。描画と Output の小窓は、今までどおり戻り値を使う。
- JS の一つの持ち主を評価する部品は、相手の物を引くために状態を受け取る。
- 相手の点は、物の中身の箱が要る。状態は中身を持たないので、評価関数は箱を引数（`boxes`）で受け取る。Python では、ノードが実行のたびに読んだ素材（板は素材の画素の数と切り抜き、3D は中身を囲む箱）から作る。JS では、エディタが読み込んだ中身から作り、読み込みが済むまでは箱が無いものとして物の `position` を見る（済んだら描き直す）。出力は Python が描くので、読み込み中の表示のずれは出力に出ない。

### 座標の決まり（AGENTS.md の Stop & ask）

- World は glTF 座標（右手系、Y 上、前方 `-Z`）、角度はパノラマの規約（+Z が正面）のままで、変換は今の一か所で行う。新しい決まりは足さない。
- 物の上のずれは、その物の中身の箱（自分の座標、`rotation` と `scale` を掛ける前）の中心から、箱の大きさに対する割合で持つ。
- 上は World の +Y。

### 状態とデータの形の変更（AGENTS.md の Stop & ask）

- `camera.look_at` の Lane を足す。値は `{"sticker": id, "offset": [x, y, z]}`、`{"point": [x, y, z]}`、`null` のどれか。`offset` は中身の箱に対する割合である。
- 評価関数の引数 `boxes`（物ごとの中身の箱）。
- 方向から向きへの変換（`look_rotation`・`lookRotation`）を、`core/world.py` と `web_src/pano_world.js` に一つずつ足す。式は上の「座標の決まり」の規約から出るもので、新しい規約は足さない。
- `sticker_state` に Look at を載せる形は ADR 0067 が持つ。

### 一致を守る test

- Python と JS が同じフィクスチャ（`v2_look_at`）を読む：動く相手、相手の切り替え、ちょうど真上・真下（すぐ前・すぐ後・どちらも無い）、同じ位置、物の回転と大きさ、箱のある物と無い物。箱はフィクスチャに書いて渡す。

## 考えた別案

- **向きの Keyframe を、相手を向くように自動で打ち直す命令**：相手や Camera を動かすたびに打ち直しが要る。関係として持てば、付いていく。
- **効き具合（0〜1）の数字を別に持つ（Blender の Influence、Earth Studio の Influence）**：Lane の Keyframe と Easing で同じことが表せるので、数字を増やさない。
- **相手があるときは、軌道を相手の周りの弧にする**：上の「決定」のとおり、見えない決まりになる。
- **使う人が Sky と World のどちらを向くかを選ぶ、空に貼った画像を相手にする**：無限に遠い物は方向だけなので、向きの Keyframe で足りる。

## Consequences

- 被写体を見たままの回り込みが、位置の Keyframe 二つと、相手一つで作れる。
- Python のノード、JS の評価関数、`sticker_state` の出力に手が入る。評価関数は、状態のほかに中身の箱を受け取るようになる。
- 相手のほぼ真上・真下を通る動きは、向きが速く変わる。エディタの表示で先に見える。
- 次の候補：空間の一点を相手に選ぶ画面、相手の切り替えの画面、相手を真ん中から外した構図。
