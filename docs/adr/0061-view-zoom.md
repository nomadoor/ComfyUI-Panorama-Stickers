# ADR 0061: 寄る操作（画角を変える）を Alt + ホイールとピンチに置き、ホイールは前へ進むままにする

## Status

Proposed（2026-11-05）

ADR 0047 の次の三つを置き換える：0047 が採らなかった候補 B（Alt + ホイールで画角）を採る（ホイールは前後のまま、Alt + ホイールと
ピンチで画角を変える）、「Sky だけの場面も普通に動ける。『Sky only』の知らせは出さない」（Sky だけの場面で
ホイールを回すと、動いたうえで一行で寄る操作を知らせる）、Preview のウィンドウの「グリッドを隠したまま絵が変わらない移動をしても
知らせない」のうちホイール（同じ知らせを出す）。ADR 0045 の「モードを内容で切り替えない」と、ADR 0047 のホイールの式は変えない。

## Date

2026-11-05

---

## 背景

1.6.0 で視点を一つにしたとき（ADR 0045、ADR 0047）、ホイールは「前へ進む」操作になった。空・背景の ERP・ペイント・Preview の画像と
動画は無限遠にあるので、前へ進んでも大きくならない。それまでの「見回しとホイールで画角」の見方では、ホイールで画角を変えて
パノラマの一部に寄れた。

- ADR 0045 は、IMAGE・VIDEO を見る Preview も同じ操作にし、「見回しとホイールで画角」だけの見方はやめるとした。比べる候補として、A「いつも
  前へ進む、画角は固定」と B「前へ進む、Alt + ホイールで画角」を挙げた。
- ADR 0047 は試作で A を選んだ。比べた試作の場面は物を置く場面で、パノラマの細かいところを見る場面では比べていなかった。
- そのため、パノラマに寄れなくなることは、失うものとして記録されなかった。Panorama Studio の 3D タブ、Preview のウィンドウ、Preview の
  ノードの上の Scene のビューアは、どれも画角を変える手段を持たなかった（`studio/stage_view.js` は画角を 100° に固定し、Scene のビューアの
  `viewFov` を変える操作も無かった）。
- 一方、Preview のノードの上で IMAGE・VIDEO を見るときだけは、旧 Preview の runtime のまま、ふつうのホイールで画角が変わった（1 イベント
  3°）。同じ Preview の中で、ホイールの意味が場所でずれていた。
- Camera タブの Frame 表示では、Sky だけの場面でホイールを回しても撮る絵は変わらず、Camera の H FOV は左の FOV の目盛りかインスペクタ
  でしか変えられなかった（Camera タブの部分は、まだ入っていない別の案を、この ADR にまとめた）。

持ち主が挙げた（2026-11-05）：パノラマの一部を大きくして細かいところを見られない場所がある。操作から見た目まで、持ち主と一つずつ決めた。

## 決定

### 二つの操作を分け、どこでも同じにする

| | マウス | トラックパッド |
|---|---|---|
| 前へ進む（今のまま） | ホイール | 二本指でなぞる |
| 寄る（視点の画角を変える） | Alt + ホイール | ピンチ（Alt + 二本指でなぞるも同じ） |

- 同じにする場所：Panorama Studio の 3D タブと Camera タブ、Preview のウィンドウ、Preview のノードの上（Scene のビューアも、IMAGE・VIDEO も）。
  旧ノードのエディタ（`PanoramaStickers`・`PanoramaCutout` のモーダル）と旧 `PanoramaPreview`（legacy）は変えない。
- ホイールの意味を、つないだ物でもポインタの下の物でも変えない。
- ピンチはブラウザに Ctrl + ホイールとして届き、マウスの Ctrl + ホイールと見分けられない。マウスの Ctrl + ホイールも寄る操作にするが、
  一覧と tooltip には出さない。
- 寄る中心は、どこでも画面の真ん中。向きと位置は変えない。
- 一段の量と、数字をドラッグする速さは、Camera タブの FOV の目盛りの矢印キーとドラッグと同じ値を使う。値（一段 2°、4 px で 1°）と一段を
  求める関数は、ノードの runtime からも使えるように下の層の `pano_camera_math.js` に一つだけ置き、目盛りもそれを読む。トラックパッドの
  細かい事象はホイールと同じく溜めて一段にし、Alt（ピンチ）が変わったら溜めた分を捨てる。奥へ回すと画角が小さくなる（寄る）。
- 視点の画角の範囲は 35°〜140°（今の `VIEW_HFOV_MIN_DEG`・`VIEW_HFOV_MAX_DEG`）。

### 意図して変えること：Preview のノードの上の IMAGE・VIDEO

Panorama Preview（`PanoramaPreviewNode`）のノードの上で IMAGE・VIDEO を見るとき、今はふつうのホイールで画角が変わる。これを Alt + ホイールと
ピンチに変える（ほかの場所とそろえるため）。ふつうのホイールは「前へ進む」になり、見回しだけの画像の表示では何も動かない。ノードの上に知らせは出さない（下の「Sky だけの場面の知らせ」）。
旧 `PanoramaPreview`（legacy）のノードは今のまま。

### 画角の数字と Reset View（見本の案 B2）

- ステージの右下の群（3D タブ、Camera タブ、Preview のウィンドウ）に、画角の数字を整数の度でいつも出す。140° が入る幅を先に取り、
  隣のボタンを動かさない。数字を左右にドラッグして変える。キーボードのフォーカスを受け、矢印キーでも目盛りと同じ一段ずつ変える。隣に画角だけを 100° に戻す小さなリセットを置き、100° のときは隠さずに無効にする。
- Reset View のアイコンを家（Tabler の `home`）に変える。原点・yaw 0・pitch 0 に加えて、画角も 100° に戻す。位置・向き・画角が全部初めの
  ときは無効にする（tooltip「Reset view · Already at the start」）。回る矢印は「この値を既定に戻す」（インスペクタの行と同じ）にだけ使う。
- Preview のノードの上には数字を出さない。右上の Reset view を家のアイコンにし、同じく初めのときは無効にし、押すと画角も戻す。
- 位置と向きの数字は出さない。

### Camera タブ

- Frame 表示の Alt + ホイールとピンチは、Camera の H FOV を FOV の目盛りの矢印キー一回分ずつ変える。Camera の位置と向きは変えない。
  Camera の Lane に記録の規則で書き、続けて回した分を Undo の 1 段にする（ふつうのホイールとは別の段）。ドラッグ・キーの移動の途中、
  読み取り専用、ロックした Camera では何もしない。範囲の端では何も変えず、知らせない（目盛りと同じ）。
- Alt を押している間、FOV の目盛りをキーボードのフォーカスと同じ見た目にし、Alt + ホイールで動くのがそこだと示す。使えるときの目盛りの
  tooltip に「FOV (Alt+Wheel)」を出す（ツールチップの書き方「名前 (操作)」。`docs/studio-ui.md` の「ツールチップ」）。
- 右下の数字は Camera の H FOV を出し、無効にする（変えるのは左の FOV の目盛り）。
- Panorama モードの Alt + ホイールは何も変えず、「Not available in Panorama mode」と一行で知らせる。
- 視点の画角と Camera の H FOV は、どちら向きにも合わせない。左の列の Camera to view が持ってくるのは、今までどおり位置と向きだけ。

### 覚えること

視点の画角は、位置と向きと同じに覚える：エディタはページを開いている間ノードごと（視点の記憶）、Preview のノードはノードごと（runtime の
記録）、ノードと大きなウィンドウの間は両方向に受け渡す（寄ったまま開き、閉じると返す。IMAGE・VIDEO が 100° で開いていたのも直る）。
ページを読み込み直すと 100° に戻る。状態にもワークフローにも保存しない。

### Sky だけの場面の知らせ

World の内容が無いときにふつうのホイールを回すと、今までどおり前へ進んだうえで、上端の中央に一行の知らせ（知らせるだけ）を出し、
`BOUND_NOTICE_SECONDS` で消す。3D タブと Preview のウィンドウは「Sky only · Alt+wheel zooms」、Camera タブは「Sky only · Alt+wheel changes the FOV」。
Preview のノードの上には出さない（持ち主：「ノード上 UI はいらない」）。

### ショートカットの一覧

View の群に「Zoom (change FOV)：Alt＋ホイール / ピンチ」を足す。Camera タブの Frame モードでは「Change Camera FOV」と書く。

規則と値の持ち主は `docs/space-and-view.md`（「寄る」「Sky だけのときのホイール」「Frame 表示」「Preview のウィンドウ」）、
`docs/studio-ui.md`（「画面の区画」「Camera タブ」「一行の知らせの種類」「ショートカットの一覧」「Preview のウィンドウ」）、
`docs/design.md`（「大きさ」「アイコン」）、`docs/preview-node.md`（「ノード上」）、`docs/legacy-node-surfaces.md`（「PanoramaPreview」）。

## 考えた別案

| 案 | 採らなかった理由 |
|---|---|
| ホイールの意味を内容やポインタの下の物で変える（World の内容が無い・空を指すときだけ画角） | 物を一つ置いた途端、指す場所を変えた途端にホイールの意味が変わる。ADR 0045 の「モードを内容で切り替えない」と ADR 0047 の考えに反する |
| ポインタの方へ寄る（画角を変えながら、ポインタの下の点を留めるように向きも変える） | 持ち主：直感的でない。寄る中心は画面の真ん中にする |
| Ctrl + ホイール（ピンチ）だけで寄る | ピンチだけを使う人には足りるが、Camera タブの Alt + ホイールとそろえるため Alt を主にする（Ctrl はピンチと見分けられないので同じに扱う） |
| 視点の画角と Camera の H FOV を合わせる（どちらかを変えると、もう一方も変わる） | 見るための画角と撮るための画角は別のもの。3D タブで寄っただけで出力が変わる、またはその逆になる |
| Preview のノードの上にも画角の数字を出す | ノードの上の表示は絵が主役で、数字は要らない（持ち主） |
| Preview のノードの上にも Sky だけの知らせの一行を出す（絵の上端の中央に重ねる） | ノードの上に新しい UI を足さない（持ち主：「ノード上 UI はいらない」） |
| IMAGE・VIDEO のノードの上に Reset view を足す | ノードの上に新しい UI を足さない。戻す道は下の Consequences |
| 位置と向きの数字も出す | 使う人の手順に要らない。画面の上の情報を増やさない |
| 数字だけを出し、画角だけのリセットはダブルクリックにする（案 A） | 戻す道が目に見えない |
| 数字の隣のリセットと Reset View を同じ回る矢印にする（案 B） | 同じアイコンが二つ並び、どちらが何を戻すか迷う。Reset View を家にした（案 B2） |
| 数字をインスペクタの値の箱の形にし、クリックで入力できるようにする（案 C） | 箱の高さ 26px が 34px のボタンの列の中で小さく見え、戻す道がダブルクリックだけになる |
| Sky だけのとき、ホイールで動かさず知らせだけを出す | パン・WASD・ジョイスティックも同じく見えない移動をする。ホイールだけ止めると扱いがそろわない（別の案から引き継いだ） |
| Sky だけのとき、上端に警告の帯を出し続ける | 見る間ずっと邪魔になる。知らせは回したときだけで足りる（別の案から引き継いだ） |
| Alt を押している間、FOV の目盛り全体を明るくし、真ん中の印を色付きにする／目盛りの頭に「Wheel」の札を出す | Alt + 左ドラッグはオービットで、Alt を押すたびに目立ちすぎる（持ち主。別の案から引き継いだ） |

## Consequences

- どの場所でも、Sky・背景・ペイント・画像と動画に寄れる。Camera タブでは、Sky だけの場面でも絵の大きさを手元で変えられる。
- Preview のノードの上の IMAGE・VIDEO で、ふつうのホイールでは寄れなくなる（意図した変更）。
  一段の量も 3° から目盛りの一段に変わる。
- Reset View のアイコンが回る矢印から家に変わり、初めの視点にいる間は無効になる。Preview のノードの上の Scene のビューアの Reset view も同じ。
- ピンチ（Ctrl + ホイール）をステージとノードの上で受けるので、その上ではブラウザのページの拡大にならない。
- 一段の量と数字のドラッグの速さは FOV の目盛りと同じ値（`pano_camera_math.js`）なので、目盛りの縮尺を変えると寄る操作も一緒に変わる。
- Preview のノードの上の IMAGE・VIDEO には Reset view が無い。寄った画角を戻す道は、Alt + ホイールとピンチか、大きなウィンドウの Reset View・
  画角のリセット（閉じるとノードに返る）。ノードの上には Sky だけの知らせも出ないので、ふつうのホイールで何も起きないことはそこでは示さない。
- Alt を押している間に出るオービットの中心の印とオービットのカーソル（ADR 0058）は、Alt + ホイールで寄る間もそのまま出す。
- ADR 0047 と ADR 0045 の Status に一行を足す（この ADR と一緒に承認する前提）。
